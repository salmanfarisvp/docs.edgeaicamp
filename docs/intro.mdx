# Physical AI Bootcamp with Arduino

**Building Intelligent Embedded & Robotic Systems on the Edge**  
Powered by [Robu.in](https://robu.in) and [Arduino.cc](https://arduino.cc)


---

## Bootcamp Vision

Physical AI Systems Bootcamp is a hands-on, intensive program designed to equip students with practical skills in building intelligent embedded and robotic systems that operate at the edge : combining AI, sensors, and real-world actuation into deployable physical systems.

This bootcamp bridges:

- **Embedded Systems**
- **Edge Computing**
- **TinyML**
- **Intelligent Control Systems**
- **Robotics**

---

## Learning Outcomes

By the end of the 2-day bootcamp, participants will be able to:

1. Explain the difference between Cloud AI and Edge AI
2. Understand the fundamentals of embedded systems using Arduino Q
3. Implement a complete TinyML pipeline using Edge Impulse
4. Deploy a trained model onto an Arduino Q
5. Design a Physical AI system architecture (Sensor → Model → Decision → Actuator)
6. Build and present a working intelligent embedded or robotic system
7. Document technical work professionally

---

## Target Audience

- CS, ECE, EEE, IT — B.Tech / M.Tech / MCA / M.Sc students
- Mixed coding and Arduino experience (2nd, 3rd, 4th year)
- Maximum **20 students** per batch
- Individual learning, group-based final project
