# Overview

Edge Impulse is the leading development platform for machine learning on edge devices, free for developers, and trusted by enterprises worldwide.

* With Edge Impulse, software developers, engineers, and domain experts can solve real problems using machine learning on edge devices without a Ph.D. or advanced embedded engineering skills. From getting started to MLOps in production, Edge Impulse provides maximum efficiency and speed on a wide range of hardware from MCUs to CPUs.  

![](https://workshop.makergram.com/assets/images/EI_homepage-727937c7021413632212b5105c89d835.png)
With Edge Impulse we can:

* Collect images from a laptop camera, phone QR code, or file upload (no device daemon required for this bootcamp)
* Collect other datasets by upload (including a data `.zip`), API, or third-party ingestion
* Split data into train and test sets with labels
* Train a model with recommended learning blocks
* Attach the trained model to an **Arduino App Lab Brick** on UNO Q
* Collaborate on TinyML projects

:::note
A data `.zip` is only for uploading samples into Studio. It is not how you put a model on the UNO Q. For the board, sign in to Edge Impulse from App Lab and select the model on the Brick.
:::


## Why we use edge impulse

![](https://workshop.makergram.com/assets/images/edge-impulse-studio-226a9fa209c8e212fb483b7e17e24183.png)

We use Edge Impulse to collect data, train a model, and attach that model to an Arduino App Lab Brick on the UNO Q. You sign in to Edge Impulse from App Lab: you do not import an Arduino library `.zip`. 


### Create Edge impulse account

Vist the [edge impulse signup website](https://studio.edgeimpulse.com/signup) and create an account first,

![](https://workshop.makergram.com/assets/images/signup-cb6a1eca08bbe85d3aa77a055c1caa6c.png)


#### Create an Edge Impulse Free Account.

First, we need to create an edge impulse account. for that go to https://studio.edgeimpulse.com/login select **Sign Up**, or if you already have an account enter **Username/Email** and **password**.

![](https://hackster.imgix.net/uploads/attachments/1323148/image_uJbGxfMuNw.png?auto=compress%2Cformat&w=740&h=555&fit=max)

#### Create Edge Impulse Project

After creating an account, we need to create an edgeImpulse project. For that click your profile and select Create a new project or use this [URL](https://studio.edgeimpulse.com/studio/select-project#create-new-project).

![](https://workshop.makergram.com/assets/images/newproject-2c3e5b4ccf4d6ef340a7124cb89d023d.png)

Then provide a project name, then click **Create new project** .

![](https://hackster.imgix.net/uploads/attachments/1323155/image_MYIOqUbxwg.png?auto=compress%2Cformat&w=740&h=555&fit=max)

Next, you can see the studio page, which means you successfully created an edge Impulse project 🎉
