# Bootcamp Overview

This bootcamp is designed as a **1-day introduction** and a **2-day full bootcamp**. Both formats are covered below.

---

## At a Glance

Hours, format, and batch size are the same for both the **1-day introduction** and the **2-day full bootcamp**.

| | |
|---|---|
| **Duration** | 1-day introduction or 2-day full bootcamp |
| **Hours** | 9:00 AM – 4:00 PM |
| **Format** | Theory + Hands-on Practicals |
| **Batch Size** | Max 20 students |
| **Final Output** | 1-day: Project Build (group). 2-day: working system + documentation |

---

## Schedule

Day 1 is shared. The **1-day introduction** ends after Session 5. The **2-day full bootcamp** continues with Session 6 and Day 2.

| **Time** | **Session** | **Type** | **Description** |
|---|---|---|---|
| **DAY 1: Foundations of Physical Intelligence** | | | |
| 9:00 – 10:00 | Sessions 1 + 2: Physical AI & Edge Computing | Theory | What is Physical AI? Sensor → Model → Decision → Actuator. Cloud AI vs. Edge AI: latency, privacy, and power. |
| 10:00 – 11:30 | Session 3: Embedded Systems with Arduino UNO Q | Practical | Hands-on with the UNO Q in **Arduino App Lab** (PC Hosted Mode). Run an example App, see Python (`main.py`) and the sketch (`sketch.ino`), and use the Bridge. |
| 11:30 – 1:00 | Session 4: TinyML Simplified | Theory + Practical | What TinyML is and how it works. Collect data and train in Edge Impulse, then attach the model from an App Lab Brick (sign in → AI models → Download → Brick Configuration). |
| 1:00 – 2:00 | Lunch | - | - |
| 2:00 – 3:40 | Session 5: Project Build | Theory + Practical | Build a complete Physical AI project as a group: camera or sensor → Edge Impulse → App Lab Brick → Bridge → actuator. |
| 3:40 – 4:00 | Session 6: Project Ideation & System Design *(2-day only)* | Team/Design | Teams form and brainstorm their Day 2 project. Define the problem, choose sensors and actuators, sketch the system architecture. On the 1-day introduction this slot is wrap-up: recap, certificates, kit return. |
| **DAY 2: Build & Showcase** *(2-day only)* | | | |
| | Recap & Architecture Review | Discussion | Quick recap of Day 1 concepts. Teams present their system design for feedback before building. |
| | Build Phase | Practical | Teams build their Physical AI systems. Facilitators help debug hardware and code issues. |
| | Testing & Documentation | Practical | Rigorous testing. Document the project on [hackster.io](https://hackster.io) or [Arduino Project Hub](https://projecthub.arduino.cc) with photos, code, and a description. |
| | Project Demonstrations | Presentation | Each team presents their working system. Live demo + explanation of architecture and challenges. |
| | Awards & Certification | Awards | Best projects recognised. Certificates issued to all participants (Salman × Robu × Arduino). |

On the 1-day introduction, Project Hub documentation and the [Day 2 project ideas](/docs/projects/overview) are optional take-home.

---

## Tools & Platforms

| Tool | Purpose |
|---|---|
| Arduino App Lab | Create, import, and Run Apps on the UNO Q (Python + sketch + Bricks) |
| Edge Impulse | Collect data and train models; attach them from an App Lab Brick after sign-in |
| Arduino Project Hub | Document and share your project |
| Telegram | Optional: bot alerts in the camera project |

:::note
This bootcamp uses **App Lab in PC Hosted Mode**. You do not need Arduino IDE, Arduino CLI, or VS Code SSH for the core sessions.
:::

## Pre-Requisites (Before You Arrive)

- [ ] Install **Arduino App Lab**: **[docs.arduino.cc/software/app-lab/](https://docs.arduino.cc/software/app-lab/)**
- [ ] Create a free **Arduino** account (App Lab will ask you to sign in for Edge Impulse models)
- [ ] Create a free account at **[studio.edgeimpulse.com](https://studio.edgeimpulse.com)** (or connect it from App Lab later)
- [ ] Create a free account at **[projecthub.arduino.cc](https://projecthub.arduino.cc)**
- [ ] Charge your laptop: sessions run 9 AM to 4 PM
- [ ] Bring a USB-C cable that supports **data**, not charge-only
