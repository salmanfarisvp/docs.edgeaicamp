Workshop Overview

A full breakdown of both days — what's covered, when, and what you'll walk away with.

At a Glance​

Duration2 Days
Hours9:00 AM – 4:00 PM each day
FormatTheory + Hands-on Practicals
Batch SizeMax 20 students
Final OutputWorking Physical AI system + documentation

DAY 1 — Foundations of Physical Intelligence​

Session 1 — Introduction to Physical AI [Theory]​

What is Physical AI? How does it differ from software-only AI? The Sensor → Model → Decision → Actuator architecture. Real-world examples and why it matters now.

Session 2 — Edge Computing Fundamentals [Theory]​

Cloud AI vs. Edge AI. Latency, privacy, and power trade-offs. Why inference on-device changes everything for robotics and embedded systems.

Session 3 — Embedded Systems with Arduino Q [Practical]​

Getting hands-on with the Arduino Q board. IDE setup, uploading code, reading sensors, controlling outputs. Serial monitor debugging.

Session 4 — TinyML Simplified [Theory + Practical]​

What TinyML is and how it works. Using Edge Impulse to collect data, train a model, and deploy it to Arduino Q — without writing ML code from scratch.

Session 5 — Guided Physical AI Project [Theory + Practical]​

Follow a complete guided project together as a group. Experience the full pipeline: sensor data → Edge Impulse → trained model → Arduino Q → actuator response.

Session 6 — Project Ideation & System Design​

Teams form and brainstorm their Day 2 project. Define the problem, choose sensors and actuators, sketch the system architecture (Sensor → Model → Decision → Actuator).

DAY 2 — Build & Showcase​

Recap & Architecture Review​

Quick recap of Day 1 concepts. Each team presents their system design for feedback before building.

Build Phase​

Teams build their Physical AI systems. Facilitators circulate and help debug hardware and code issues.

Testing & Documentation​

Test the system rigorously. Document the project on hackster.io or Arduino Project Hub with photos, code, and a description.

Project Demonstrations​

Each team presents their working system to the group. Live demo + explanation of the architecture and challenges.

Awards & Certification​

Best projects recognised. Certificates issued to all participants (Salman × Robu × Arduino).

Tools & Platforms​

ToolPurpose
Arduino IDE 2.xWrite and flash code to Arduino Q
Edge ImpulseCollect data, train and deploy TinyML models
Arduino Project Hub / hackster.ioDocument and share your project
Serial MonitorReal-time debugging output
Python 3.x (optional)Custom data processing scripts

Pre-Requisites (Before You Arrive)​

  • Install Arduino IDE 2.x — arduino.cc/en/software
  • Create a free account at edgeimpulse.com
  • Install the Arduino Q board package via Boards Manager
  • Charge your laptop — sessions run 9 AM to 4 PM
  • Check your hardware kit — see Bootcamp Inventory
