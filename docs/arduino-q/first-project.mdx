# Your First Project

In this exercise you'll write a working Arduino program from scratch, use the Serial Monitor to print output, and read from the built-in IMU sensor.

---

## Project 1 — Blink with Serial Output

```arduino
// Blink + Serial output
void setup() {
  Serial.begin(115200);
  pinMode(LED_BUILTIN, OUTPUT);
  Serial.println("Arduino Q — ready!");
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  Serial.println("LED ON");
  delay(500);

  digitalWrite(LED_BUILTIN, LOW);
  Serial.println("LED OFF");
  delay(500);
}
```

**To run it:**
1. Paste the code into a new sketch (**File → New Sketch**)
2. Click **Upload** (→)
3. Open **Tools → Serial Monitor** and set baud rate to **115200**
4. You should see `LED ON` / `LED OFF` alternating

**Your Turn:**
- [ ] Upload the sketch and confirm the LED blinks.
- [ ] Confirm you see `LED ON` / `LED OFF` messages in the Serial Monitor.
- [ ] Change the `delay(500)` values to speed up or slow down the blink and re-upload.

## Project 2 — Read the IMU

The Arduino Q has a built-in IMU. Let's read accelerometer values.

```arduino
#include <Arduino_LSM9DS1.h>

void setup() {
  Serial.begin(115200);
  while (!Serial);

  if (!IMU.begin()) {
    Serial.println("IMU initialization failed!");
    while (1);
  }
  Serial.println("IMU ready");
}

void loop() {
  float x, y, z;

  if (IMU.accelerationAvailable()) {
    IMU.readAcceleration(x, y, z);

    Serial.print("X: "); Serial.print(x);
    Serial.print("  Y: "); Serial.print(y);
    Serial.print("  Z: "); Serial.println(z);
  }

  delay(100);
}
```

**What to expect:**
- Lay the board flat: `Z ≈ 1.0`, `X ≈ 0`, `Y ≈ 0`
- Tilt it: watch X and Y change
- These raw acceleration values are what a gesture recognition model will learn from

**Your Turn:**
- [ ] Upload the sketch and open the Serial Monitor.
- [ ] Lay the board flat and confirm `Z ≈ 1.0`.
- [ ] Tilt the board left/right and forward/back — watch X and Y respond.
- [ ] Try holding the board vertically and note which axis reads `≈ 1.0` now.

## Project 3 — RGB LED Rainbow

If your board has an RGB LED (check your board pinout):

```arduino
// Adjust pin numbers for your specific board
#define PIN_R 22
#define PIN_G 23
#define PIN_B 24

void setup() {
  pinMode(PIN_R, OUTPUT);
  pinMode(PIN_G, OUTPUT);
  pinMode(PIN_B, OUTPUT);
}

void setColor(int r, int g, int b) {
  analogWrite(PIN_R, r);
  analogWrite(PIN_G, g);
  analogWrite(PIN_B, b);
}

void loop() {
  setColor(255, 0, 0);   delay(500); // Red
  setColor(0, 255, 0);   delay(500); // Green
  setColor(0, 0, 255);   delay(500); // Blue
  setColor(255, 165, 0); delay(500); // Orange
  setColor(128, 0, 128); delay(500); // Purple
}
```

:::tip
Check your specific Arduino Q pinout diagram for the correct RGB LED pin numbers. These vary by board variant.
:::

**Your Turn:**
- [ ] Upload the sketch and verify each color cycles correctly.
- [ ] Add a new color of your choice (e.g. cyan: `0, 255, 255`) to the sequence.
- [ ] Adjust the `delay()` values to create a faster or slower fade effect.
