# Installation

Get your development environment ready in four steps.

---

## Step 1 — Install Arduino IDE

Download **Arduino IDE 2.x** from the official site:

👉 [https://www.arduino.cc/en/software](https://www.arduino.cc/en/software)

Choose your OS (Windows / macOS / Linux) and follow the installer.

:::tip macOS
On macOS, drag the Arduino IDE app to your Applications folder and open it once — macOS will ask to allow it.
:::

---

## Step 2 — Install the Board Package

1. Open Arduino IDE
2. Go to **File → Preferences** (macOS: **Arduino IDE → Settings**)
3. In the **Additional boards manager URLs** field, paste the URL for your Arduino Q package:

```
https://downloads.arduino.cc/packages/package_index.json
```

4. Click **OK**
5. Go to **Tools → Board → Boards Manager**
6. Search for your board (e.g., `Arduino Mbed OS Nano Boards` or `Arduino Q`)
7. Click **Install** and wait for the download to complete

---

## Step 3 — Connect the Board

1. Plug your Arduino Q into your laptop using the **USB-C cable** from your kit
2. Wait a few seconds for the OS to detect it
3. Go to **Tools → Port** and select the port that appears (e.g., `COM3` on Windows, `/dev/cu.usbmodem...` on macOS)
4. Go to **Tools → Board** and select **Arduino Q** (or the matching board name)

:::note Windows Users
If no port appears, you may need to install the USB driver manually. Download it from the manufacturer's support page and run the installer, then reconnect the board.
:::

---

## Step 4 — Install Required Libraries

Open **Tools → Manage Libraries** and install:

| Library | Purpose |
|---|---|
| `Arduino_LSM9DS1` | IMU (accelerometer + gyroscope) |
| `PDM` | Microphone (usually pre-installed) |
| `TensorFlowLite` | ML inference runtime |
| `ArduinoBLE` | Bluetooth LE (if needed) |

Search for each library by name and click **Install**.

---

## Verify Your Setup

Once everything is installed:

1. Go to **File → Examples → 01.Basics → Blink**
2. Click the **Upload** button (➡ arrow icon)
3. Watch the built-in LED on your Arduino Q blink on and off

If the LED blinks — you're all set!

:::warning Upload Error?
If you get an error like `avrdude: stk500_getsync()`, try:
- Double-pressing the reset button on the board to enter bootloader mode
- Re-selecting the port in **Tools → Port**
- Trying a different USB cable
:::
