# Arduino Q — Overview

The **Arduino Q** is the main microcontroller board used in this workshop. It is designed for edge AI and TinyML applications — small, low-power, and capable of running ML inference directly on the chip.

---

## Board Highlights

| Feature | Specification |
|---|---|
| Processor | 32-bit ARM Cortex-M |
| Clock Speed | Up to 120 MHz |
| Flash Memory | 1 MB |
| RAM | 256 KB |
| Connectivity | USB, UART, I2C, SPI |
| Built-in Sensors | IMU (accelerometer + gyroscope), Microphone |
| Power | USB or 3.7 V LiPo |
| Form Factor | Arduino Nano compatible |

Update the specifications above with the exact specs for your Arduino Q variant.

## Why Arduino for Edge AI?

- **Arduino IDE** is beginner-friendly with thousands of libraries
- **TensorFlow Lite for Microcontrollers** has first-class Arduino support
- **Edge Impulse** deploys directly to Arduino boards in one click
- **Large community** — easy to find help and examples
- **Low cost** — accessible for workshops and students
