# Run Example Projects

Arduino App Lab comes with a set of built-in example projects that you can run directly on the UNO Q without writing any code. These are a great way to explore what the board can do and get familiar with how Apps and the Bridge work in practice.

---

## How to Run an Example

1. Open the **Arduino App Lab** desktop app (PC Hosted Mode). It is not a website in your laptop browser.
2. Connect the UNO Q with a data-capable USB-C cable and wait until the board is detected.
3. Open the **Examples** section.
4. Click an example to open it.
5. Click **Run** in the top right and wait for the App to start on the board.

:::note
You cannot set a built-in example as a startup App directly. Use **Copy and edit app** first if you want to save or modify it.
:::

---

## Example Projects

- **Blink LED**: the classic blink sketch, a good first run to confirm your board is connected and working.
- **Blink LED with UI**: control the LED on and off through a simple web interface served by the board.
- **Air Quality on Matrix**: read air quality sensor data and display it on the onboard LED matrix.
- **UNO Q Pin Toggle**: manually toggle digital pins from a web UI to test hardware connections.
- **Bridge Echo**: Python sends a message to the Arduino via the Bridge, and the Arduino echoes it back to the shared console.
- **Camera Stream**: stream live video from a connected camera to a browser interface.
