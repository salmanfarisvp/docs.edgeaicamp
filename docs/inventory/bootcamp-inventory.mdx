# Bootcamp Inventory

Hardware used during the Physical AI Bootcamp — powered by [Robu.in](https://robu.in) and [Arduino.cc](https://arduino.cc).

:::info Hardware Policy
All Arduino Q boards and sensor modules used during the workshop will either be **collected at the end** of the bootcamp or made available for **on-the-spot purchase**. A consolidated inventory report will be shared with the Robu and Arduino teams.

Shared sensor kits will be retained and reused across future bootcamps.
:::

| Light Sensor (LDR / Digital) | 5 | Analog / Digital | Ambient detection systems |

:::note Built-in Sensors on Arduino Q
The Arduino Q has a built-in **IMU** (accelerometer + gyroscope) and a built-in **microphone**. Many projects can be built using only the board itself — no extra sensors needed.
:::

## Software Checklist

Install these before arriving on Day 1:

- [ ] **Arduino IDE 2.x** — [arduino.cc/en/software](https://www.arduino.cc/en/software)
- [ ] **Arduino Q board package** — via Boards Manager (see [Installation Guide](/docs/arduino-q/installation))
- [ ] **Edge Impulse CLI** — `npm install -g edge-impulse-cli`
- [ ] **Free Edge Impulse account** — [edgeimpulse.com](https://edgeimpulse.com)
- [ ] **Free hackster.io account** — [hackster.io](https://www.hackster.io) *(for project documentation)*
- [ ] **Python 3.x** *(optional)* — for custom scripts

---

## Hardware Handling Rules

- Handle the Arduino Q board by the edges — avoid touching components directly
- Do **not** apply voltages above 3.3 V to GPIO pins unless specified
- Always double-check wiring before powering up
- Return all shared sensors to the pool at the end of each session
- Robotics kits — return fully assembled and charged

:::tip Missing Something?
If an item is missing from your kit, notify the facilitator before the session starts. Spare units are available.
:::
