Bootcamp Inventory

:::info Hardware Policy All Arduino Q boards and sensor modules used during the workshop will either be collected at the end of the bootcamp or made available for on-the-spot purchase. A consolidated inventory report will be shared with the Robu and Arduino teams.

Shared sensor kits will be retained and reused across future bootcamps. :::

Software Checklist​

Install these before arriving on Day 1:

  • Arduino IDE 2.x — arduino.cc/en/software
  • Arduino Q board package — via Boards Manager (see Installation Guide)
  • Edge Impulse CLI — npm install -g edge-impulse-cli
  • Free Edge Impulse account — edgeimpulse.com
  • Free hackster.io account — hackster.io (for project documentation)
  • Python 3.x (optional) — for custom scripts

Hardware Handling Rules​

  • Handle the Arduino Q board by the edges — avoid touching components directly
  • Do not apply voltages above 3.3 V to GPIO pins unless specified
  • Always double-check wiring before powering up
  • Return all shared sensors to the pool at the end of each session
  • Robotics kits — return fully assembled and charged

:::tip Missing Something? If an item is missing from your kit, notify the facilitator before the session starts. Spare units are available. :::
